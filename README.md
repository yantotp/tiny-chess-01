A deterministic 4 KB Python chess engine: a 0x88 board, alpha-beta search with a transposition table, null-move pruning, late-move reductions and a capture quiescence search, packed to fit the entrypoint cap.

## Run it

```sh
MAKEFUN_ENV_URL=<the trial env> python3 -P -s main.py
```
